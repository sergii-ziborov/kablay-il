# Screenshot sources

The 24 PNG files are full-resolution iPhone and iPad simulator captures of the running application, refreshed on 10 October 2026 from build 40. English, Russian and Hebrew each have four iPhone and four iPad images. The app's UI tests include the capture flows. The JPG is a representative Pro Profile screen supplied from TestFlight; it contains no account contact information.

These are product documentation assets, not signing or App Store Connect exports. They contain no customer requests, private addresses, conversations, OTPs or credentials. The [gallery](../../gallery.md) presents every image and explains each screen. UI details can change after the recorded build.
